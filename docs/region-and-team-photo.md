# 지역 표시와 팀 사진 API

공고 `region`, `participationRegion`은 저장 및 조회 시 알려진 지역명 내부 공백을 정리합니다. `전　국`은 `전국`, `대 구`는 `대구`가 됩니다. `경기 성남` 같은 서로 다른 지명 사이 공백은 유지합니다. 기존 DB 값도 응답에서 정리하며 원본 CSV 추적 정보와 장소 설명은 보존합니다.

팀 생성·목록·상세·수정 응답에 `photoUrl`이 포함됩니다. 업로드 구현 이후의 최신 계약은 [비공개 S3 팀 사진](team-photo-s3.md)을 따릅니다. 요청에서 URL 직접 등록은 중단하고, 팀 생성 후 파일 업로드 API를 호출합니다.

응답의 `photoUrl`은 화면 표시용이며 요청에 그대로 돌려보내지 않습니다.

- 사진이 없으면 응답은 `null`입니다. 프런트에서 팀 이름 첫 글자를 표시합니다.
- 수정 요청에서 생략하거나 null을 보내면 유지하고, 빈 문자열을 보내면 제거합니다.
- 새 사진은 `POST /api/v1/teams/{teamId}/photo`의 multipart `file`로 보냅니다. `photoUrl`에 URL을 직접 입력하지 않습니다.
- 객체 키를 저장하며 조회 응답의 `photoUrl`은 10분짜리 임시 URL입니다.

기존 DB는 백업하고 앱을 정상 종료한 뒤 `docs/sql/team-photo-url-h2.sql`을 적용합니다. 이 작업에서 운영 DB는 변경하지 않았습니다.
