2. docs/sql/contest-korea-target-research-20261116.sql을 /home/ubuntu/contest-korea-target-research-20261116.sql로 전송합니다. 시크릿·DB 파일은 업로드하지 않습니다.
3. 적용 직전에 앱을 정상 중지하고 MainPID=0·DB 점유 없음을 확인한 후 새 DB 백업을 만듭니다.

6. 미확인 1개는 남을 수 있으므로 잔존 0건·64개 전체 완료라고 표현하지 않습니다. 검증 후 COMMIT; quit하고 서비스를 시작합니다.
7. 기존 상세 API의 enrollmentRequirement를 프런트에서 다시 조회합니다. 경로·응답 필드·enum 변경은 없습니다.
