# 온라인 공고의 지역 조건

`GET /api/v1/announcements/{announcementId}/eligibility`와 추천 후보 판정에 동일하게 적용합니다.

- 참가 가능 지역(`participationRegion`), 개최 지역(`region`), 장소 안내(`venueNote`) 중 하나에 `온라인`이 포함되면 지역 조건을 충족한 것으로 처리합니다. 글자 사이 공백과 온라인·오프라인 병행 표시도 포함합니다.
- 응답의 `conditions`에 `code: PARTICIPATION_REGION`, `status: SATISFIED`가 내려갑니다.
- 온라인 접수 방법만으로는 온라인 공고로 판정하지 않습니다.
- 온라인 표시가 없을 때는 개최·현장 참석 지역(`region`) 또는 명시적인 오프라인 장소 안내(`venueNote`)가 있는 공고만 지역을 검사합니다. 모든 팀원의 참석 가능 지역 중 하나가 참석 장소의 시·도와 일치해야 `SATISFIED`이며, 한 명이라도 불일치·미설정이면 `TEAM_INFO_REQUIRED`입니다. 장소를 시·도로 식별할 수 없는 경우도 확인 필요입니다.
- 외부 API의 참가 가능 지역(`participationRegion`)은 필수 참석 장소로 간주하지 않습니다. CSV의 `required_region`은 거주 자격인지 참석 장소인지 확인되지 않아 판정에 사용하지 않습니다. 참석 장소가 확인된 데이터는 `region` 또는 명시적인 오프라인 `venueNote`로 보완해야 합니다.
- 재학 상태·추가 자격 조건은 별도로 검사하므로 전체 `status`는 `MISMATCH` 또는 `TEAM_INFO_REQUIRED`일 수 있습니다. 인원은 공고 참가 조건 API와 추천에서 판정하지 않으며, D02에서만 최소 인원 미달·최대 인원 초과를 안내합니다.
- 참석 장소와 비교할 때 `SEOUL` 같은 사용자 지역 코드와 `서울특별시` 같은 시·도 명칭을 연결합니다. 팀원의 지역 설정 변경은 추천의 갱신 필요 여부에도 반영합니다.

API 경로와 응답 필드 변경, DB 마이그레이션은 없습니다. 프런트는 전체 판정과 각 조건의 상태를 구분해서 표시해야 합니다.
